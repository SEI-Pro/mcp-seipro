## O que mudou

- **RFC 0019 — proposta**: adotar práticas do repo irmão `pink` (Kanoê MCP),
  levantadas numa comparação lado a lado dos dois codebases.
- **RFC 0019 §2.1 implementado**: `SKILL.md` gerado automaticamente das
  tools MCP (`src/todos/skill.py`, introspecção in-process via
  `fastmcp.Client`, mesmo mecanismo do `pink.skill`) + subcomando
  `todos skill install` (`--agent`/`--scope`/`--target`) +
  `scripts/regen_mcp_skill.py` para regenerar `.agents/skills/todos-mcp/SKILL.md`
  em dev/CI.
- **Correção**: `_FIXED_COMMANDS` (RFC 0018) só olhava
  `_app.registered_commands`, não `registered_groups` — um subgrupo typer
  (`add_typer(...)`, como o novo `skill`) era despachado como nome de tool
  por engano (`todos skill install` virava uma tentativa de chamar a tool
  `"skill"`). Corrigido para incluir os dois; teste de regressão em
  `tests/test_cli_dispatch.py`.
- **RFC 0019 §2.4 implementado**: CI de bump de versão agora também exige
  `changelog/<versão>.md` (mesma disciplina do `pink`), não só que
  `__version__` tenha mudado.
