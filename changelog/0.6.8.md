## O que mudou

- **Novo módulo `src/todos/output.py`**: fronteira única entre o resultado de
  uma tool (stdout, sem markup, para consumo por script/`--json`) e mensagens
  de erro do CLI voltadas ao usuário (stderr, com markup Rich). `cli_call.py`
  e `server.py` passam a usar `emit_result`/`emit_human` em vez de chamar
  `sys.stdout.write`/`sys.stderr.write` diretamente.
- Conteúdo dinâmico (mensagens de exceção, nome de tool digitado na CLI)
  agora é escapado (`rich.markup.escape`) antes de entrar numa string com
  markup Rich — evita que um colchete não balanceado no texto de erro
  derrube o próprio caminho de tratamento de erro com `rich.errors.MarkupError`.
