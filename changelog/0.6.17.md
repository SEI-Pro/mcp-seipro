## O que mudou

- **Docs (RFC 0022)** — registra investigação (não confirmada) do POST de
  assinatura de documento via backend web (`assinar_documento_web`) falhando
  contra uma instância real: `assinarSenha()` submete o form de forma
  síncrona (não assíncrona, como uma hipótese inicial chegou a considerar),
  mas dois defeitos no código atual impedem a submissão de reproduzir esse
  fluxo corretamente — `hdnFormaAutenticacao="S"` não é enviado, e o override
  de `orgao` usa o nome de campo errado (`selOrgaoAssinante` em vez de
  `selOrgao`). Nenhuma correção de código incluída nesta versão — ver
  `docs/rfc/0023-assinatura-documento-web-post-senha-falha.md` para os
  próximos passos recomendados antes de tentar novamente contra uma
  instância real.
